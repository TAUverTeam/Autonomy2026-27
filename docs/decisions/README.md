# Decision records

One short file per significant choice, so future team members know **why** the system is the way it is.
Rules and when to write one: [documentation-standard.md](../documentation-standard.md#level-4-decision-records).

To add one: copy [0000-template.md](0000-template.md) to the next free number, fill it in, add it to
the list below, and include it in the same pull request as the change it explains.
